# Contributing

Jason Stys: small reviewed changes, deterministic evidence and honest limitations.

Use only original/publicly licensed synthetic examples. Do not add operational aircraft identifiers or sensitive locations. Run every README gate; regenerate/check source navigation and update measured docs. Keep dependency pins/hashes and immutable workflow refs. Do not suppress audit findings, weaken gates, upload artifacts/caches or silently substitute mock outcomes for unavailable native/service checks.

Add independent analytical/oracle cases for mathematical changes, regression tests for bugs and actual-service browser journeys for UI behavior. Review limits, privacy, same-origin protections and data-quality messaging before release. This is advisory education, not guidance/control/targeting or operational certification.
